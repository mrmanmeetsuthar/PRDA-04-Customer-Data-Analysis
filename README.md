# PRDA-04: Customer Data Analysis

**Customer Shopping Behaviour Analysis using SQL and Microsoft Power BI**

**Author:** Manmeet Suthar

---

## 📌 Project Overview

This project focuses on analyzing customer shopping behaviour using transactional data collected from 10 different shopping malls in Istanbul between 2021 and 2023.

The objective is to understand customer purchasing patterns based on gender, age groups, product categories, payment methods, and shopping mall locations.

Microsoft Power BI is used to create interactive dashboards and visualizations to identify business insights and provide recommendations for improving sales and customer engagement.

## 🎯 Project Objectives

* Analyze shopping distribution according to gender.
* Identify which gender purchases more products.
* Compare revenue generated by different genders.
* Analyze purchasing patterns across age groups.
* Identify the most popular product categories.
* Examine relationships between payment methods and customer characteristics.
* Compare shopping mall performance.
* Visualize findings using Power BI dashboards.
* Provide business insights and recommendations.

## 📊 Dataset Description

The dataset contains customer shopping information from 10 shopping malls in Istanbul between 2021 and 2023.

### Dataset Features

| Column         | Description                       |
| -------------- | --------------------------------- |
| invoice_no     | Unique invoice number             |
| customer_id    | Customer identification           |
| gender         | Customer gender                   |
| age            | Customer age                      |
| category       | Purchased product category        |
| quantity       | Number of products purchased      |
| price          | Price per product in Turkish Lira |
| payment_method | Cash, credit card, or debit card  |
| invoice_date   | Transaction date                  |
| shopping_mall  | Shopping mall location            |

## 🧹 Data Preparation

The following preparation steps were performed:

* Imported customer transaction data.
* Checked column names and data types.
* Inspected missing and duplicate values.
* Converted numerical columns into appropriate data types.
* Created a Revenue column.
* Created Age Groups for demographic analysis.

### Revenue Calculation

Revenue is calculated using:

`Revenue = Quantity × Price`
